# Changelog

All notable changes to Polski Daily. Versions follow [docs/versioning.md](docs/versioning.md).

## [0.1.0] - 2026-11-16

### Added
- Setup screen that asks for your first language, current Polish, goal level, goal date and daily minutes, so the plan is built around a real target.
- Today screen with a four-step daily session: review cards, next lesson, tutor conversation, and a log for Polish used outside the app.
- 10 lessons for the start of A1. Each has a note written for Greek, Italian or Spanish speakers (with an English fallback) that compares the Polish rule with the learner's own language.
- Practice questions with on-screen Polish letters, and a hint when the answer is right apart from the Polish marks.
- Review cards from finished lessons on a 1, 2, 4, 8, 16 day schedule, so words come back before they are forgotten.
- AI tutor on the Claude API that writes at the learner's level and explains the main mistake in the learner's language or in English.
- Access code and a daily message cap for the tutor, because every message costs API credit on a public demo.
- Plan screen with total hours, real pace over the last 14 days, a projected date for each level, and the minutes a day the goal needs.
- Backup download and restore in Settings, because progress is saved only in the browser.
